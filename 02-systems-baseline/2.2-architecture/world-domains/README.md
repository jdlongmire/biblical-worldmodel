# World Domains

Purpose: canonical BWM subject-matter domains to which Foundations and Historical Frameworks are applied.

Initial domains:

- cosmology / physical order;
- Earth history / geology;
- biology / life systems;
- anthropology;
- archaeology and chronology;
- covenant / redemptive history.

A World Domain is not itself a Historical Framework. Domain content should identify which foundations constrain it, which Historical Frameworks apply, which observations and empirical propositions belong to the domain, and which open tensions remain.

Domain indexes initially organize accepted BWM content and interfaces. They do not authorize wholesale migration of active research packages.
