# Research Programme Interfaces

This surface is the canonical BWM gateway registry for externally authoritative research programmes.

BWM owns these interface records. The source repositories own their research.

An interface records the exact source state reviewed by BWM, the programme's source type, its BWM role, exported propositions or constraints actually consumed, typed dependencies, unresolved items, and integration conflicts.

## Rules

1. A source branch is not an accepted version pin. Accepted interfaces record an immutable source commit.
2. BWM shall not strengthen source confidence, modality, scope, or empirical standing.
3. Source changes do not silently alter BWM. Refresh is explicit.
4. Integration conflicts are recorded and returned to the owning programme when source disposition is required.
5. Internal repository structures remain independent. This interface standardizes only the BWM-facing contract.
6. DTE and UTE are not registered here because they are BWM comparative interpretive/model families, not external research programmes.
7. PFH is not registered here while it remains the BWM-owned Pre-Fall Hypothesis.

See WP-BWM-0026 for the governing gateway contract and provenance of this architecture.
