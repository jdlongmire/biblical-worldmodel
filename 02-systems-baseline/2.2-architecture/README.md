# Publication architecture

The intended implementation is MkDocs Material under `03-solutions-baseline/site/`, built by GitHub-hosted Actions and published through GitHub Pages. Static-site content, responsive assets and future media metadata are product-owned. Canonical research and Atlas ownership remain external.

Community/contact is a separate dependency on the public site. External form providers and Giscus remain design inputs, not selected or activated services. ThinxHome is not the deployment backend or CI runner.
