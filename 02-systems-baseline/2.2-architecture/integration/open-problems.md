# BWM Open Problems Register

Status: Integration governance artifact under WP-BWM-0013
Type: Integration

## Purpose

Maintain an explicit register of unresolved tensions, missing mechanisms, evidentiary gaps, and cross-framework dependencies.

## Required fields

Each open problem should record:

- problem ID;
- concise statement;
- affected Foundation / Framework / World Domain;
- why the problem matters;
- current evidence;
- competing interpretations;
- what would count as resolution;
- responsible work package or source programme;
- confidence/status;
- last review date.

## Initial architectural open problems

The following categories are expected to populate this register as work is promoted:

- DFM initialization and retrodiction limits;
- PFH duration, reproduction, demographics, and age-accounting zero-point;
- CHFM unresolved mechanism and stratigraphic boundary questions;
- radiometric and radiocarbon interpretation across relevant boundaries;
- human antiquity versus human mortality chronology;
- framework interaction conflicts across cosmology, geology, biology, anthropology, and archaeology;
- source-of-truth drift between BWM interfaces and external research repositories.

## Governance rule

An unresolved problem shall remain visible until explicitly disposed. BWM shall not convert silence, lack of current explanation, or model preference into a solved status.
