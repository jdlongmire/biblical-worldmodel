# Show us the strongest objections

A framework worth examining should make its liabilities visible. The aim is to understand the strongest version of a criticism before responding.

## Make an objection inspectable

State the target claim or page, your argument, primary evidence, and the conclusion you think follows. Explain what a satisfactory response would need to address.

[Submit an objection on GitHub](https://github.com/jdlongmire/biblical-worldmodel/issues/new?title=Objection%3A%20)

Substantive programme objections require review in the repository that owns the claim. This site can explain and route a challenge; it cannot settle it by changing a public summary.

The public objection-response register is in preparation. Existing programme liabilities should be inspected at the [canonical sources](research-programmes.md).
