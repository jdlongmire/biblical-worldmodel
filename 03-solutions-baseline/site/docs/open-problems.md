# Open problems and remaining burdens

An open problem is not a completed explanation. This site will identify unresolved mechanisms, evidential debits, severe tests, and proposed or retired auxiliaries when supported by canonical records.

## Reading status labels

- **Research proposal:** a claim or mechanism offered for examination.
- **Open problem:** an unresolved question or burden.
- **Tested result:** a result with a stated test and scope; not automatic validation of an entire framework.
- **Revised or retired:** a claim changed or withdrawn, with the reason preserved.

## Problems this project currently carries

These are genuine burdens on the framework as a whole, stated as they stand, not placeholders awaiting an easy resolution.

- **Where testimony bears on physical questions.** Treating Scripture as evidentially relevant to cosmology, earth history, or biology requires an argument for why testimony crosses into those domains, not just an assertion that it does. See [foundations](foundations.md).
- **How much predictive success is enough.** An explanation that anticipates a result in advance carries more weight than one built to accommodate a result already known (see [evidence](evidence.md)), but no threshold has been set here for how many advance predictions would count as adequate confirmation, or how many failures would count against a proposal.
- **Guarding against motivated interpretation.** A project built to defend a prior theological commitment has to show its claims are falsifiable in practice, including publishing results that go against a favored proposal. That discipline is still being built into this site's public content, not yet demonstrated at scale.
- **Domain-specific evidential burdens.** Earth history, cosmology, and biology each carry their own unresolved mechanisms and evidential debits. Those are addressed on their own pages as the corresponding canonical programmes mature, not resolved on this page.
- **What functional maturity has to explain.** If creation includes features that appear historically old, an account owes an explanation of why that is not equivalent to a deceptive appearance. This is a burden for the canonical source behind [creation](creation.md), not settled here.
- **How much of the historical narrative is load-bearing.** Which parts of the biblical history this project is committed to defending, and which are open to revision without abandoning its theological core, is not yet stated with precision.

The programme-specific register is in preparation. Consult [canonical research](research-programmes.md) for current technical status.
