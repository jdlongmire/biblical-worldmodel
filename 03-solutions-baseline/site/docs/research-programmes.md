# Research programmes and canonical sources

This site is a public explanation and navigation layer. It does not replace the repositories that own technical programme claims. Each programme below is developed and reviewed in its own repository, structured as a Lakatosian research programme (see [methodology](methodology.md) and the [glossary](sources.md)). This page indexes them and, where a formal paper has been published, links to it; it does not summarize their arguments or current confidence levels here.

## Programmes

| Programme | Orientation | Canonical source |
|---|---|---|
| Logic Realism Theory (LRT) | Logical constraints and formal foundations | [Repository](https://github.com/jdlongmire/logic-realism-theory) |
| Triadic Reality Theory (TRT) | Foundations involving logic, information, action, and actuality | [Repository](https://github.com/jdlongmire/triadic-reality-theory) |
| Designed Functional Maturity (DFM) | Initial conditions, functional maturity, historical inference | [Repository](https://github.com/jdlongmire/designed-functional-maturity) |
| Catastrophic Hydrotectonic Flood Model (CHFM) | Proposed catastrophic geophysical reconstruction | [Repository](https://github.com/jdlongmire/catastrophic-hydrotectonic-flood-model) |
| Creation Actualization Cosmology (CAC) | Alternative cosmological research programme founded on a different historical boundary condition | [Repository](https://github.com/jdlongmire/creation-actualization-cosmology) |
| Functional Cosmological Deployment (FCD) | Creation treated as a scoped general-relativistic initial-data problem | [Repository](https://github.com/jdlongmire/creation-cosmology-programmes) |

These short orientations are not status judgments. Read each source's current claims, verification, objections, and limitations directly. Additional programme guides will be added after source review.

When a public page and its canonical source differ, the source controls. Report discrepancies through [community and feedback](community.md).
