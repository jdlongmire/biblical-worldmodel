This site is a public explanation and navigation layer. It does not replace the repositories that own technical programme claims.

| Programme | Orientation | Canonical source |

These short orientations are not status judgments. Read each source's current claims, verification, objections, and limitations. Additional programme guides will be added after source review.

When a public page and its canonical source differ, the source controls. Report discrepancies through [community and feedback](community.md).
