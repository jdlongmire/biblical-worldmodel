# Compare frameworks

Fair comparison starts by understanding each framework on its own terms. This section will compare Biblical WorldModel proposals with conventional deep-time reconstruction, old-earth creationism, progressive creation, evolutionary creation, and conventional young-earth frameworks.

## Comparison questions

- How is Scripture interpreted?
- Which initial conditions and chronology are assumed?
- How are geology, cosmology, and human origins explained?
- What could falsify an auxiliary hypothesis?
- Which problems remain unresolved?

The comparison matrix is in preparation. Positions will not be invented to fill empty cells. See [methodology](methodology.md).
