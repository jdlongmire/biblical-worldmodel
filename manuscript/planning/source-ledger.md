# Source and Verification Ledger

| ID | Claim / Topic | Candidate Chapter | Primary Source Sought | Source Located | Location / Pages | Source Type | Confidence | Verification Status | Notes / Divergence |
|---|---|---|---|---|---|---|---|---|---|

## Confidence

- **HIGH** — verified primary source
- **MEDIUM** — reliable secondary source with specific location/page support
- **LOW** — paraphrase, tertiary treatment, or incomplete sourcing
- **UNCERTAIN** — cannot presently assess

## Rules

Primary before secondary. Never fabricate citations. Never present secondary material as primary. Use “as cited in” when primary material is available only through a secondary source. Record substantive source divergence rather than silently harmonizing it.
