# Source transcription exports

Double-spaced DOCX review copies of the `.md` transcriptions one directory up, for handing to
David Williams as reviewable, markup-able files (Word comments/track-changes) rather than raw
Markdown.

**The `.md` transcriptions in `sources/` are the source of truth.** Files here are derived,
regenerate-on-change artifacts — if a transcription is edited, its export here is stale until
regenerated. Do not hand-edit a `.docx` in this folder and treat that as the authoritative text;
correct the Markdown and re-render.

Rendered with the DWBA `manuscript` baseline (Times New Roman 12, black text, double-spaced,
page numbers), matching `chapters/exports/`.
