# MxM Construct

This directory contains the repository-scoped MxM construct used to preserve working guidance, continuity, memory, and executable means for Biblical WorldModel.

It does **not** define a new assistant identity, deployed aide, or external runtime. The repository root [`MXM.md`](../MXM.md) is the bootstrap and continuity contract; [`AGENTS.md`](../AGENTS.md) supplies repository instructions for AI agents.

## Structure

- [`meta-harness/`](meta-harness/) — mission, mind, morals, and related repository-governance guidance.
- [`memory/`](memory/) — repository-scoped continuity material and retained state where governed by the construct.
- [`means/`](means/) — scripts, tests, and executable support used by the repository construct.

Product implementation belongs under [`03-solutions-baseline/`](../03-solutions-baseline/). Human/operator runbooks and machine-facing operational guidance belong under [`06-operations/`](../06-operations/).

When repository memory, chat memory, or prior assistant statements conflict with current repository state, current repository state governs.
