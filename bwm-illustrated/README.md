# BWM Illustrated

**Working title:** *The Biblical World Model: An Illustrated Atlas of Creation, History, and Reality*

**Status:** Concept / preproduction. This folder develops an oversized, illustrated coffee-table book based on the Biblical WorldModel (BWM). It is an editorial and visual prototype, not a new source of canonical scientific or theological claims.

## Editorial proposition

Use illustrated plates to explain biblical history, world domains, and BWM's research programme: individual landscape pages in current production (plate style guide adopted 2026-11-13), and two-page encyclopedia spreads in the first published iteration. Each combines a large hand-colored plate, numbered callouts, concise prose, Scripture references, and an epistemic-status panel.

## Governance

BWM is the integration/publication layer. Source research stays authoritative in its designated programme repositories. Textual claims, scientific models, dates, diagrams, and ESV quotations require independent verification before print. The generated proof-of-concept image is illustrative only and is not an approved factual diagram. No public deployment is authorized by this prototype.
