# Contributing to Biblical WorldModel

Clone `https://github.com/jdlongmire/biblical-worldmodel.git` with your own authorized Git client. Read AGENTS.md and MXM.md, then run `python3 05-mxm-construct/means/scripts/session-start.py`.

Use a dedicated branch/worktree and a scoped package from `04-work-packages/`. The repository is public; commit only public project material. JD Longmire is the Principal Operator and thinx is the existing acting assistant, not a new deployment created here.

Run the README checks before committing and publishing authorized work. GitHub is this product's process and publication host. ThinxGit and Home runtime changes are outside scope. A site build environment will be specified in WP-BWM-0001; no MkDocs install or Pages deployment exists yet.

Work packages and their imported briefs are now the project backlog. Bridge forwarding records route here; do not maintain a second active copy there. Live site and browser checks remain pending implementation.
