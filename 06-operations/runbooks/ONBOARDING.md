# Contributing to Biblical WorldModel

Clone `https://github.com/jdlongmire/biblical-worldmodel.git` with your own authorized Git client. Read AGENTS.md and MXM.md, then run `python3 05-mxm-construct/means/scripts/session-start.py`.

Use a dedicated branch/worktree and a scoped package from `04-work-packages/`. The repository is public; commit only public project material. JD Longmire is the Principal Operator and thinx is the existing acting assistant, not a new deployment created here.

Run the README checks before committing and publishing authorized work. GitHub is this product's process and publication host. ThinxGit and Home runtime changes are outside scope. The site is deployed at https://worldmodel.thinxai.net/. Follow the root README for the pinned, isolated MkDocs build environment.

Work packages and their imported briefs are now the project backlog. Bridge forwarding records route here; do not maintain a second active copy there. Build and browser verification are implemented under `03-solutions-baseline/site/scripts/`; retain results for the revision changed.
