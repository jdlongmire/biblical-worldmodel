# WP-BWM-0028: CMD Foundations and Origins-Mode Taxonomy

## Purpose

Refine and disposition the September 2026 working paper *Designed Functional Maturity, Designed Time and Emergence, and Undirected Time and Emergence* into the accepted BWM component architecture.

The package separates three concerns currently carried together in the working paper:

1. Christian Methodological Designism (CMD) as BWM-wide methodological and epistemic governance.
2. DFM, DTE, and UTE as comparative **origin modes**.
3. DFM as the BWM historical framework for the creation and initialization boundary.

DTE and UTE are comparison classes. This package does not establish them as BWM research programmes.

## Governing refinement

The target architecture is:

`CMD -> BWM -> origin-mode taxonomy -> instantiated historical/research frameworks`

CMD governs inquiry. BWM integrates the worldmodel. DFM/DTE/UTE classify explanatory treatments of beginnings. DFM is instantiated in BWM through the existing DFM historical-framework interface and its external canonical research programme.

## Required outputs

- CMD jurisdiction and methodological-governance candidate.
- Canonical origins-mode taxonomy for DFM/DTE/UTE.
- Initialization taxonomy that distinguishes functional/systemic initialization from historical-record claims.
- Integration of `Model + Interpretation -> Expectations` with the existing observation/history/purpose method.
- Explicit Lakatosian anti-degeneration controls.
- Disposition map from the source working paper into canonical BWM surfaces.
- Cross-links to DFM, PFH, CHFM, epistemic hierarchy, and relevant world domains.

## Key constraints

### Functional maturity is not a universal solvent

The working paper's Level 5 category requires decomposition. BWM already distinguishes functional maturity from chronicle-maturity. This package will preserve and sharpen that constraint.

Candidate burden ladder:

1. logical/nomic initialization;
2. physical/systemic boundary initialization;
3. relational initialization;
4. organismal/ecological functional initialization;
5. chronicle or historical-record initialization.

The categories are analytical. They do not imply that every proposed instance is warranted.

### Observation is not history

Present observations constrain historical reconstruction but are not identical to the reconstructed sequence. The existing canonical candidate schema remains controlling:

`H = R(O, M, I, B)`

The proposed shorthand `Model + Interpretation -> Expectations` will be normalized against this schema rather than introduced as a competing method.

### Comparative discipline

For each origin mode, identify:

- hard-core commitments;
- revisable auxiliaries;
- domain jurisdiction;
- expected observations;
- accommodation costs;
- discriminating observations;
- failure conditions;
- predicted surplus.

No programme receives permission to absorb every datum through unconstrained auxiliaries.
