# Candidate: Model, Interpretation, and Expectations

## Compact principle

`Model + Interpretation -> Expectations`

This is a useful public shorthand. For canonical analytical work it is expanded so assumptions and observations remain visible.

## Canonical integration

Existing BWM reconstruction schema:

`H = R(O, M, I, B)`

where present observations `O`, process model `M`, initialization assumptions `I`, boundary/historical assumptions `B`, and reconstruction procedure `R` produce inferred history `H`.

For comparative testing, define an expectation relation:

`E = X(M, A, C)`

where:

- `M` = model or framework;
- `A` = explicit auxiliary, initialization, and boundary assumptions;
- `C` = test context;
- `X` = expectation-generating interpretation;
- `E` = expected observation or result.

Observed result `O` is then compared with `E`. Evidential consequences attach first to the claim level that generated `E`, in accordance with the canonical BWM epistemic hierarchy.

## Why this matters

A measurement does not contain its historical interpretation. Yet interpretations are not arbitrary. Once a model and its assumptions are specified, they generate expectations that can be compared against observations.

The methodological chain is:

`given evidence -> explicit model/assumptions -> interpretation/reconstruction -> expectation -> test -> disposition`

For retrodictive work:

`present state -> chronometric/process model + initialization/history assumptions -> retrodictive result -> historical identity claim`

The historical identity claim requires its own warrant.

## Discriminatory force

An observation has high discriminatory force between two models when their pre-specified expectations materially diverge.

An observation may have high evidential importance and low discriminatory force if both models independently expect it.

This distinction prevents consilience from being dismissed while also preventing compatibility from being mistaken for discrimination.

## Governance

Where practical, expectations should be recorded before severe testing. Post hoc accommodation must be labeled as such and should not receive the same evidential credit as successful risky prediction.
