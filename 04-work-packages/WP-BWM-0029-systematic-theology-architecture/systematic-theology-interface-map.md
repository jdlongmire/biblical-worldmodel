# Systematic Theology Interface Map

Status: Candidate
Work package: WP-BWM-0029
Date: 2026-09-25

## Purpose

Define directional interfaces between proposed Systematic Theology and the existing BWM architecture.

## Foundation interfaces

| Foundation | Supplies to Systematic Theology | Return path |
|---|---|---|
| Canonical epistemic hierarchy | Scripture-primary authority and claim evaluation | Doctrinal tensions route to re-exegesis, not authority inversion |
| Hermeneutics | Scripture-interprets-Scripture, canonical and historical-grammatical constraints | ST records interpretive dependencies |
| TRT/LRT pinned interface | Logic/ontology constraints where explicitly consumed | ST does not fork or redefine external source authority |
| Semantic Actualism | admissibility/actualization distinctions where relevant | ST uses only through explicit interface |

## Historical Framework interfaces

| Framework | ST supplies | Framework owns |
|---|---|---|
| DFM | creation doctrine, goodness, Creator-creature distinction, purpose constraints | initialization/functional-maturity historical model |
| PFH | imago Dei, original communion, stewardship, temptation/sin, Fall/curse doctrine | admissible pre-Fall history and Fall boundary |
| CHFM | judgment/providence/covenant constraints where warranted | Flood physical/historical mechanism |
| Post-Fall history | sin/curse/covenant/redemption doctrine | historical sequence and chronology |

## World Domain interfaces

| Domain | ST supplies | Domain owns |
|---|---|---|
| Cosmology/Physical Order | creation/providence constraints | physical/cosmological models |
| Earth History/Geology | creation/judgment constraints where textually warranted | geological observations/models |
| Biology/Life Systems | creation, human uniqueness, stewardship boundaries | biological observations/models |
| Anthropology | imago Dei, personhood, agency, corruption, accountability | biology, populations, cognition, language, culture |
| Archaeology/Chronology | human/covenantal historical constraints | artifacts, contexts, dating/chronology models |
| Covenant/Redemptive History | covenant/sin/redemption/Church/eschatology doctrine | canonical-historical tracing |

## Integration interfaces

Integration owns:
- cross-domain invariants;
- dependency maps;
- contradiction/tension register;
- evidence/model comparison;
- open-problem routing;
- canonical impact analysis.

Systematic Theology exports explicit doctrinal constraints and confidence/status.

Integration returns:
- contradiction candidates;
- empirical tensions;
- dependency impacts;
- requests for re-exegesis;
- unresolved cross-domain questions.

Integration cannot silently mutate doctrine.

## Cross-cutting interface examples

### Fall

ST-3 defines sin, temptation, curse, noetic effects, culpability.
PFH locates and models the Fall boundary.
Anthropology consumes post-Fall human-condition constraints.
Integration checks consistency.

### Adamic guilt

WP-BWM-0028 retains H1 while open.
No canonical ST export occurs until disposition.
Romans 5 analysis is a doctrinal/exegetical dependency.
Anthropology may not assume either imputation or non-imputation as settled.

### Glorification

ST-8 owns glorification/impeccability doctrine.
Covenant/Redemptive History owns terminal historical placement.
Anthropology consumes final-state personhood constraints where relevant.
Integration checks Eden/New Creation asymmetry.

### Creation

ST-2 owns doctrine of creation and creaturehood.
DFM owns initialization-history questions.
Cosmology/Biology own empirical models.
Foundations govern epistemic ordering.
Integration prevents doctrinal claims from being converted into unsupported physical mechanisms.

## Interface invariant

> No layer may silently answer a question owned by another layer merely because the answer is convenient to its model.

Cross-layer claims require an explicit interface and source-of-truth pointer.
