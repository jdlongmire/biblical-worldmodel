## Migration principles

1. Work packages remain provenance records.
2. Accepted content is promoted as canonical derivatives rather than erasing source history.
3. Open hypotheses remain in their source WPs.
4. Existing canonical artifacts should be moved only when ownership/navigation benefit exceeds link churn.
5. Where physical movement is unnecessary, create canonical pointers/interfaces.
6. Doctrinal and historical representations may coexist when they answer different questions.
