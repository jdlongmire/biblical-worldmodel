# Comparative appraisal protocol v0.1

## Models

M1: all major archaic-human differentiation post-Flood. M2: differentiation post-Fall but pre-Flood, with surviving admixture through the founding family. M3: mixed pre/post-Flood differentiation. M4: conventional deep-time reconstruction as a data-fitting comparator.

## Model comparison rubric

Score each model only after a sourced dataset and preregistered parameter range exist. Each category is **unscored** at this stage.

| Category | Required evidence | Avoid |
|---|---|---|
| Scriptural warrant | Explicit text and defensible inference | Treating silence as a dated event |
| Genome-wide fit | SNP patterns, tract length, coalescent uncertainty | Selecting only introgression percentages |
| Bottleneck feasibility | Founder pedigree, allele retention, heterozygosity | Eight independent founders assumption |
| Morphological fit | Multivariate fossil and modern variation | Single-trait comparisons |
| Stratigraphic coherence | Specimen-level sediment context and independent boundary | Dating the Flood boundary from the fossils it is used to classify |
| Chronological feasibility | Generation and demographic model under each textual chronology | Equating Adam-to-Flood with Fall-to-Flood |
| Predictive severity | New discriminators, held-out samples | Ad hoc initialization per contradiction |
| Parsimony | Explicit auxiliary assumptions and penalties | Rewarding models for unconstrained parameters |

**Citation control:** Earlier work-package bibliography entries are provisional pointers. Verify authorship, year, title, DOI, and original text before upgrading to HIGH confidence.

## Initial critical finding

M2 can move some divergence processes earlier than M1, reducing pressure on post-Flood generation counts. It simultaneously creates a severe inheritance problem: extinct antediluvian population ancestry must pass through the small founding family to explain genomic traces in living people. M3 has more degrees of freedom, so its apparent fit must be complexity-penalized.

The modern-human morphological range is a useful null comparison; fossil population classification requires combinations of traits and genomic evidence. Reproductive compatibility supports genetic relatedness but does not resolve whether all populations were contemporaneous with the Flood.

## Disposition

Open research. No model accepted. Next gate: verify original creationist sources, populate fossil site ledger, implement and validate a pedigree-aware genetic simulation, then report failure cases before any canonical promotion.
