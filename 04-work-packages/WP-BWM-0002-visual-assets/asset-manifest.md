## Manifest Fields Required at Promotion

Before an asset moves to APPROVED, record:

- final filename/path;
- generating source or source-artifact reference;
- generation/revision date;
- intended pages/components;
- alt-text recommendation;
- crop-safe notes;
- canonical source dependency, if any;
- JD approval reference;
- replacement/supersession relationship, if applicable.

## Reference Mockups

The existing mockups contain embedded interface text and therefore are not production page assets. Their status must remain **REFERENCE / DO NOT DEPLOY AS PAGE** unless deliberately repurposed as a screenshot illustrating the site itself.
